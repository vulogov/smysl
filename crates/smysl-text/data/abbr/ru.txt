# ru — tokens after which a sentence boundary is suppressed. Format: see `en.txt`.
#
# The Russian list carries more multi-dot forms than the others (`т.е.`, `т.д.`, `н.э.`),
# and they are what makes the token rule scan back over `.` as well as letters: a token that
# stopped at the first dot would look up `е.` and find nothing.
#
# `ё` is not folded here. The lists are matched against the text as it was normalised, and
# `analyze.rs` is where ё→е belongs — a segmenter that folded would have to fold the text too,
# and the text is what the offsets are into.

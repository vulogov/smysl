# Every argument each subcommand accepts, one `command  argument` pair per line — and, since
# TX-P2 step 3, every argument's `[possible values: …]` beside it. A choice is a capability:
# `text append` arrived as a new value of `<ACTION>` and this file did not move by one line,
# which means a *removed* action would have been just as invisible.
#
# The third CLI gate, and it exists because the other two are blind to this one thing.
# `cli()` registers all twenty-two subcommands from the COMMANDS table unconditionally; its
# `match c.name` arms only *add arguments*. So deleting an arm leaves the command present and
# strips its flags — invisible to `tests/dispatch.rs::every_command_dispatches`, which invokes
# each command with no arguments, and invisible to `command_table_matches_section_23`, which
# checks the table rather than the parser. Seven such mutants survived at 1.1 and this is what
# reaches them.
#
# It is compared inside `cargo test` rather than by a Makefile target on purpose. `make
# api-check` guards the library surface the same way, and nothing that measures coverage can
# see a Makefile — the reason `doc-output` was wired into the test suite in 0.13.
#
# Globals appear on every command, so dropping one shows up twenty-two times and dropping a
# command's own argument shows up once. Both are visible; neither is silent.
#
# Identical under `--no-default-features --features cli`, the default build, and
# `--all-features`: the arms are not feature-gated, so what a build *accepts* does not change
# with its features, only what it then does. Verified, not assumed.
#
# Regenerate with `make cli-surface` when a change here is deliberate.

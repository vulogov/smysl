# The facade's public surface, as `cargo public-api --all-features --simplified` sees it.
#
# This is the contract. Publishing in 0.9.0 turned every name below into something people can
# build against, and `Hybrid` changed shape twice inside 0.7 while nobody was counting — so
# the point of this file is that a change to the list has to be *typed*, not merely allowed to
# happen. Same idea as `crates/smysl-pack/tests/golden-packs.txt`: the value is not that the
# contents are right, it is that a diff is a decision.
#
# It records the facade rather than every crate. The eleven behind it expand to about 11 600
# lines of simplified surface, and a diff nobody reads is decoration rather than a gate. That
# much still holds. What used to follow it did not: "what that file would have caught,
# `cargo-semver-checks` catches properly".
#
# It does not, on the facade. `cargo public-api` returns this same list with or without
# `--simplified`, because a re-export from another crate is a `pub use` line neither tool can
# expand — and `cargo-semver-checks` has the identical blind spot. Run against `smysl` it
# reports "no semver update required" for the 0.12 rename of `Error` to `AnyError`, although
# v0.11.0 exported `smysl::Error` and nothing exports it now. **This file caught that rename;
# the semver gate did not.**
#
# So the division is the other way round from how it was written. For the facade's *names*,
# this file is the gate. For everything behind a name — methods, signatures, variants —
# `make semver` is, because it reads each library crate's own rustdoc rather than the facade's
# re-exports. `tests/public-api-counts.txt` covers the third case neither sees: a public item
# added to a library crate by accident, which is nobody's break and so nobody's failure.
#
# Regenerate with `make api`. Check with `make api-check`.

# How large each library crate's public surface is, one line per crate.
#
# The third gate, and it exists because the first two each have a blind spot that the other
# does not cover.
#
#   `tests/public-api.txt` records the facade. `cargo public-api` on the facade returns the
#   same list with or without `--simplified`, because a re-export from another crate is
#   recorded as `pub use` and never expanded — so that file can say `Store` is exported and
#   cannot see one single method of it.
#
#   `make semver` reads every item in every crate, methods included, and understands the
#   semver rules rather than comparing text. But it reports *breaks* only: a public item
#   added by accident is not a break, so nothing says a word about it. It also needs a
#   published baseline, and it does not run at all on a crate listed in SEMVER_BREAKING.
#
# So: a count. Not the items — the eleven crates expand to about 11 600 lines of simplified
# surface, and the reasoning in `public-api.txt` still holds, that a diff nobody reads is
# decoration rather than a gate. A count is eleven lines, a human reads it in five seconds,
# and a number that moves without anybody meaning it to is exactly the signal that was
# missing. What it cannot see is an addition and a removal that cancel; `make semver` sees
# the removal.
#
# A change here is not a failure. It is a question: did you mean to?
#
# Regenerate with `make api`. Check with `make api-check`.

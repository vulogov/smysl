# The **pure** public surface: `--no-default-features`.
#
# The companion to `public-api.txt`, which records `--all-features`. Between them they bound
# what a consumer can see, because the three surfaces are strictly nested — no-default is a
# subset of default, which is a subset of all-features — and `make api-check` asserts that
# nesting as well as the two endpoints.
#
# This one exists because the other one was not enough. `public-api.txt` alone froze the
# maximum, so a name could stop being reachable on default features while the recorded surface
# never moved: the README recommends `default-features = false` for the pure library, and that
# path had nothing checking it at all.
#
# What the pure surface deliberately excludes is the 37 ingest and provider names, and the
# three semantic ones. No async runtime, no HTTP client, no argument parser — rule B, verified
# by `make purity` rather than promised here.
#
# Regenerate with `make api`. Check with `make api-check`.
